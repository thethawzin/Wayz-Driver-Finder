# Wayz-Driver-Finder
# 🚕 Naypyitaw Route-Based Taxi Driver Search System

### Find the Right Driver. Choose Your Route. Travel with Ease.

A web-based transportation platform designed to help people in Naypyitaw find suitable taxi drivers based on their preferred routes and travel destinations.

---

## About the Project

**Naypyitaw Route-Based Taxi Driver Search System** (Wayz Driver Finder) is a group-developed web application that aims to simplify the process of finding taxi drivers in Naypyitaw.

Traditional transportation arrangements can be inconvenient when users have difficulty finding drivers who travel along their desired routes. Our system addresses this problem by providing an accessible platform where users can explore driver information, view locations, calculate distances, and contact drivers directly.

The primary focus is simplicity, accessibility, and convenience.

## Key Features

- **Route-Based Driver Search:** Explore taxi driver options based on transportation routes.
- **Interactive Map:** View relevant locations and geographical information.
- **Distance Calculation:** Calculate the distance between selected locations in kilometers.
- **Direct Driver Contact:** Use the Call Now feature to contact drivers directly.
- **Contact Information:** Access relevant email and administrator contact details.
- **User-Friendly Interface:** Navigate the platform through a simple and accessible web interface.
